# Willowbrook Adult Family Home — Website Prototype

A frontend-only, fully interactive prototype for an Adult Family Home in Seattle, Washington.
Built with HTML5, CSS3 and vanilla ES6 JavaScript. No frameworks, no backend, no build step.

## Run it locally

1. Download the `adult-family-home` folder.
2. Open `index.html` in a browser — that's it.

For a closer-to-production experience (and to avoid `file://` quirks in some browsers), serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
