Accessibility Statement

We want this website to be usable by everyone, including people using assistive technology.

Our commitment

This prototype has been built with the intention of meeting WCAG 2.2 Level AA practices. Accessibility is treated as a requirement, not an afterthought.

Keyboard navigation

All interactive elements — navigation, forms, accordions, gallery filters and the image lightbox — are operable by keyboard. A visible focus indicator appears on every focusable element, and a "skip to main content" link is the first focusable item on each page.

Screen-reader compatibility

Semantic HTML5 landmarks are used throughout. Form inputs have associated labels, validation errors are announced through live regions, the lightbox is a modal dialog with focus trapping, and the mobile menu manages focus and aria-expanded state.

Colour contrast

Body text and interactive elements are designed to meet or exceed a 4.5:1 contrast ratio against their backgrounds. The primary palette uses deep forest green and warm ivory specifically to support readable contrast.

Text resizing

Layouts use relative units and flexible grids, so text can be enlarged to 200% without loss of content or functionality and without horizontal scrolling at standard breakpoints.

Image alternative text

All meaningful images carry descriptive alternative text. Placeholder illustrations are described as illustrative, so assistive technology users are not misled about what is depicted.

Reduced motion

The stylesheet respects the prefers-reduced-motion media query, disabling transitions and smooth scrolling for users who have requested reduced motion at the operating-system level.

Known limitations

This is a prototype. It has not yet been audited by an independent accessibility specialist or tested with a full range of assistive technologies. Real user testing is recommended before launch.
